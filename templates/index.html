⚙️ LOCAL AI ENGINE CONFIGURATION

Local Open-Weight AI via Ollama

TrailBuddy AI runs on Ollama with open-weight models (default: llama3.2). All prompt processing takes place directly on your machine with zero cloud dependencies.

1
Install Ollama

Download the free open-source Ollama runtime for Windows, macOS, or Linux at ollama.com.

2
Pull the Open-Weight Model

Open PowerShell or Terminal and download llama3.2 (approx. 2 GB):

ollama pull llama3.2
3
Start Ollama Service

Start the Ollama daemon or run the model:

ollama run llama3.2
